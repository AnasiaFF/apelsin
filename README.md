# Название: Конференции.РФ  
Данный проект помогает людям арендовывать помещения для конференций и иных мероприятий.
# Стек:  
Node.js, Express, SQLite, EJS, Bootstrap  
# Устновка:  
npm install  
Запуск: node server.js. База данных создаётся автоматически и наполняеться seed-данными. 
http://localhost:3000

# Роли:   
Пользователь может просматривать свои заявки, если меропрятие завершено может оставлять отзыв о нём. Так же создавать заявки на помещения для мероприятий, указывать дату, время, способ оплаты.  
Админ имеет доступ до всех заявок, может просмотривать личные данные пользователей, менять статусы заявок(Новая, назначено и завершено).
